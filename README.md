## Featured Projects

### ✈️ Vivley - AI-Powered Travel Platform *(Currently Building)*
An AI-powered travel booking platform designed to deliver faster, more intuitive hotel search and booking experiences than traditional OTAs. Users can search in natural language, refine results in conversation, and confirm bookings directly—without redirects.

**Tech:** Fastify, Typescript, React, Next.js, OpenAI API, PostgreSQL(Supabase)

### 🎮 GameSight - AR Application for RoboCup SPL
Developed an augmented reality application for Meta Quest 3 that overlays live RoboCup soccer match data in real-time. Implemented controller-based field placement, passthrough depth mapping, and computer vision for automatic field detection.

**Tech:** Unity (C#), Meta XR SDK, Sentis, Depth APIs

### 🐾 PetCare - Vet Clinic Management System
Full-stack web application for managing veterinary clinic appointments with normalised database schemas, Flyway migrations, and real-time availability tracking.

**Tech:** Spring Boot, JDBC, Flyway, PostgreSQL
